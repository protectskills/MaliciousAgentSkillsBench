# Nova-tracer Runtime Subset

This directory vendors the runtime pieces of Nova-tracer used by the dynamic
execution sandbox.

Included:

- `hooks/` for Claude Code hook execution
- `rules/` for NOVA prompt-injection rules
- `config/` templates written by `executor/nova_setup.sh`
- `LICENSE`

The upstream Nova-tracer project is MIT licensed. Keep
`code/executor/nova-tracer/LICENSE` with this vendored copy.
